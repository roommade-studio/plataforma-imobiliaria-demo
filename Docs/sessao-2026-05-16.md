### 2.2 KPI cards — gauge semicircular (iterações)

#### Contexto

Os 7 KPI cards do `/dashboard` tinham um indicador de progresso que passou por quatro versões nesta sessão antes de funcionar.

#### Iteração 1 — `SemiGauge` com `strokeDasharray` + `sweep-flag=0` (quebrado)

```tsx
const d = 'M 10 50 A 40 40 0 0 0 90 50'  // sweep=0 = antihorário = para BAIXO
```

**Bug:** `sweep-flag=0` desenha o arco no sentido anti-horário de (10,50) para (90,50), o que em coordenadas SVG (y invertido) significa que o arco vai para **baixo** da corda, fora do `viewBox="0 0 100 55"`. Apenas os dois endpoints em y=50 ficavam visíveis — apareciam como dois pontos.

#### Iteração 2 — Badge colorido (`PctBadge`) — substituição temporária

Substituída a gauge por um `<span>` com cor de fundo proporcional à porcentagem (verde/azul/vermelho). Renderizou corretamente mas não era o visual desejado.

#### Iteração 3 — `SemiGauge` revisado com `sweep-flag=0` novamente (mesmo bug)

Mesmo erro de `sweep-flag`, mesmo resultado de dois pontos.

#### Iteração 4 — `SemiCircleGauge` com `sweep-flag=1` + trigonometria (solução definitiva)

**Causa raiz confirmada:** `sweep-flag=0` usa o arco que passa abaixo da corda. A solução é `sweep-flag=1` (horário), que passa acima (pelo topo do semicírculo).

**Implementação final:**

```tsx
function SemiCircleGauge({ percentage, color }: { percentage: number; color: string }) {
  const angle    = (percentage / 100) * 180
  const radians  = (angle - 180) * (Math.PI / 180)
  const x        = 50 + 40 * Math.cos(radians)
  const y        = 50 + 40 * Math.sin(radians)
  const largeArc = angle > 180 ? 1 : 0

  return (
    <svg viewBox="0 0 100 55" width="100" height="55">
      {/* Arco de fundo — sempre completo */}
      <path
        d="M 10 50 A 40 40 0 0 1 90 50"
        fill="none" stroke="#E5E7EB" strokeWidth="8" strokeLinecap="round"
      />
      {/* Arco preenchido — endpoint calculado por trigonometria */}
      {percentage > 0 && (
        <path
          d={`M 10 50 A 40 40 0 ${largeArc} 1 ${x} ${y}`}
          fill="none" stroke={color} strokeWidth="8" strokeLinecap="round"
        />
      )}
      {/* Porcentagem centralizada */}
      <text x="50" y="46" textAnchor="middle" fontSize="13" fontWeight="bold" fill={color}>
        {percentage}%
      </text>
    </svg>
  )
}
```

**Por que funciona:**
- A flag `sweep-flag=1` (horário) de (10,50) para (90,50) traça o arco **acima** da corda, passando por (50,10) — o topo do semicírculo. Fica totalmente dentro do viewBox.
- O endpoint do arco preenchido é calculado por `cos/sin`, posicionando-o exatamente no ângulo proporcional à porcentagem. Sem `strokeDasharray` — sem nada que possa falhar silenciosamente.
- `large-arc-flag = 1` apenas quando o ângulo ultrapassa 180° (porcentagem > 100%, não ocorre em uso normal).

**Verificação do cálculo (exemplos):**

| % | angle | radians | x | y |
|---|-------|---------|---|---|
| 0% | 0° | -π (-180°) | 10 | 50 | ← ponto esquerdo |
| 50% | 90° | -π/2 (-90°) | 50 | 10 | ← topo |
| 100% | 180° | 0° | 90 | 50 | ← ponto direito |

**Cor por threshold:**
```tsx
function gaugeColor(pct: number) {
  return pct >= 80 ? '#16A34A' : pct >= 50 ? '#2563EB' : '#DC2626'
}
```

#### Reestruturação do layout do card KPI

Antes (row): `[info esquerda] [gauge direita]`  
Depois (column): `[icon + label] → [gauge centralizado] → [Realizado | Meta]`

```tsx
<div className={styles.kpi__card}>
  <div className={styles.kpi__header}>
    <span className={styles.kpi__icon}>{kpi.icon}</span>
    <p className={styles.kpi__label}>{kpi.label}</p>
  </div>
  <div className={styles['kpi__gauge-area']}>
    <SemiCircleGauge percentage={kpi.progress} color={gaugeColor(kpi.progress)} />
  </div>
  <div className={styles.kpi__bottom}>
    <div className={styles['kpi__bottom-item']}>
      <span className={styles['kpi__bottom-label']}>Realizado</span>
      <span className={styles['kpi__bottom-value']}>{kpi.value}</span>
    </div>
    {kpi.meta && (
      <div className={styles['kpi__bottom-item']}>
        <span className={styles['kpi__bottom-label']}>{kpi.meta}</span>
      </div>
    )}
    {kpi.trend && (
      <div className={styles['kpi__bottom-item']}>
        <span className={styles['kpi__meta--trend']}>{kpi.trend}</span>
      </div>
    )}
  </div>
</div>
```
